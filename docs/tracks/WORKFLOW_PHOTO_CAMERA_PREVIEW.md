# 照片到实时相机预览

合并工作流以清晰单人照片建立参考坐标。待照片定位完成后可开启相机；照片中已审阅并激活的切口在同一人的视频画面上重新投影。未确认候选和低置信边界仅供照片核对，实时显示仍受姿态和可见性检查约束。

此实验默认关闭。构建 Demo 时设置 `VITE_WORKFLOW_PHOTO_CAMERA_EXPERIMENT=true`，再从 `web` 运行 `npm run build`。本地开发可用同一个变量运行 Vite；浏览器需要 localhost 或 HTTPS 才能申请相机权限。

- 手机可选前置或后置相机，双指缩放；电脑在画面上用滚轮缩放。
- 镜像先改变相机像素，再计算投影；缩放不重新运行识别。
- 照片上的张力线、皱纹线和切口使用 SVG 显示。导出 PNG 会合成照片和标注。
- GitHub 继续使用仓库现有皱纹模型配置。公开 HF 的模型分片由部署独立维护。

这是决策辅助可视化实验，不是诊断、手术指令或受监管医疗器械。Stage 1/Stage 2 均不构成临床验证结果。
