# 手机工作台布局调整（2026-11-27）

## 范围

仅调整 `/app/workflow` 的手机布局：宽度不超过 560px 且使用触摸交互时启用。桌面和鼠标窄窗保留原有布局。RSTL、皱纹检测/引导、受控标记、切口生成与微调的算法和参数没有改动。

整理基线为 master `116527f1d39a707bc28ec5d43d97d4a1d467f488`，保留该版本已有的相机功能开关、镜像及摄像头选择行为。

## 原有操作的新位置

| 原有操作 | 手机位置 |
| --- | --- |
| 上传照片 | 底部正中，直接调用原有文件选择输入 |
| 开启/关闭摄像头 | 底部左侧 |
| 暂停/继续、导出视频、导出图片 | 底部右侧「更多」 |
| RSTL、皱纹显示开关 | 「皮肤纹理」面板标题行 |
| 皱纹检测、自动微调、恢复；手动微调、撤销、重置、点模式和数量 | 「皮肤纹理」同一个纵向滚动面板 |
| 受控标记、确认识别、清除等原有画布工具 | 「切口设计」面板 |
| 切口线显示开关 | 「切口设计」面板标题行 |
| 肿物类型、边界方式、切口规划参数 | 「切口规划」折叠区 |
| 候选微调参数 | 「候选微调」折叠区 |
| 审阅人输入、确认及校验反馈 | 面板内常驻的一行，不再另设展开按钮 |

新增入口只用于展开/收起已有控件，没有新增业务动作。原有控件的 ID、事件和共享状态保留；稳定的 portal 容器在布局切换时移动现有节点。
