# Model card · wrinkle-yolov8s-seg-640

本文描述 `/personalized` 个性化 RSTL 流程中使用的浏览器端皱纹分割模型。许可与来源链条见同目录
[NOTICE.md](NOTICE.md)（**许可未确认**）；算法上下文见 [`docs/tracks/PERSONALIZED_RSTL.md`](../../../../docs/tracks/PERSONALIZED_RSTL.md)。

## 1. 模型概况

| 项 | 值 |
|---|---|
| 架构 | YOLOv8s-seg（实例分割） |
| 格式 / opset | ONNX / 17 |
| 输入 | `images`，`[1,3,640,640]`，float32，RGB，范围 `[0,1]` |
| 输出 | `output0` `[1,39,8400]`（框 + 类别 + 32 维 mask 系数）、`output1` `[1,32,160,160]`（mask 原型） |
| 类别 | `forehead`、`frown`、`wrinkle` |
| 推理置信阈值 | **0.07**（低阈值刻意取高召回，详见 §4） |
| NMS IoU / mask 阈值 | 0.45 / 0.5 |
| 运行位置 | 浏览器 `onnxruntime-web` WASM，execution provider `wasm` |
| 完整性校验 | 分片拼接后校验总字节数 + SHA-256（生产默认开启，见 `yolo_wrinkle_onnx.js`） |

## 2. 训练数据

**未知。** 上游仓库未提供数据集说明、样本量、人群分布、年龄/性别/肤色构成或标注规程。
因此无法评估该模型在不同肤色、年龄、光照或摄像头条件下的表现差异，也无法排除数据集偏差。
这是把它限制为 secondary cue、且不允许其改变切口几何的直接原因。

## 3. 预期用途

- **预期**：研究性地为个性化 RSTL 微调提供皱纹位置证据（严格并集融合后作为低置信线索）。
- **非预期**：临床诊断、病灶识别、切口方向决定、肿物边界判定、任何自动化手术建议。
- 输出**不是**解剖学皱襞标注，只是"看起来像皱纹的像素区域"。

## 4. 为什么阈值是 0.07

该模型在本项目的输入分布（浏览器摄像头单帧、正脸、无专业光照）上置信度整体偏低。
0.07 是为**高召回**选的工程阈值：宁可多召回再由下游几何约束筛掉，也不漏掉真实皱纹证据。
代价是误检偏多，因此下游必须依赖严格并集 + 皮肤域硬约束 + 禁区掩膜 + 置信度加权来抑制误检，
单看本模型输出的 precision 不具备临床意义。阈值与融合规则的完整说明见
[`docs/tracks/PERSONALIZED_RSTL.md`](../../../../docs/tracks/PERSONALIZED_RSTL.md)。

## 5. 已知局限

- 训练数据、评估指标、人群覆盖全部未知，**没有**本项目自测的 precision/recall 数字。
- 眼镜、胡须、头发、阴影、强反光会产生误检；`frown` 与 `wrinkle` 类别语义边界模糊。
- 侧脸、遮挡、低分辨率下退化明显；不含时序一致性，多帧结果可能抖动。
- 未在任何临床数据集上验证；不得据此声称任何临床有效性。
